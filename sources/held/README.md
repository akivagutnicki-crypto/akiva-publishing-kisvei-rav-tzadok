# Held back from the build

These Sefaria exports are modern editions (Sifrei Izhbitza–Radzin, Bnei Brak)
whose license Sefaria lists as "unknown". They are not bundled into the site;
the library reads them live from Sefaria instead.

Once republishing rights are confirmed, move a file to `sources/sefaria/` and
it will be built into the site on the next deploy.
