# Beit Yaakov footnotes — alignment staging (not published)

This staging file maps **704 original Hebrew footnotes** from Bereishis, Noach and Lech Lecha against the available 183-section interlinear source edition.

Automated matching outcome: **329 high-confidence**, **134 require editorial review**, **208 uncertain**, and **33 have no translated section in the current reader**. The remaining **1,788** footnotes from Vayera through Vayechi have not yet been aligned because their corresponding interlinear edition is not in the reader.

The original note texts and translations are **not committed to the public repository**. They are retained in the user's private translation worklist. No existing Hebrew/English phrases, footnotes, or reader UI are changed by this staging file.

The mapping is **not a verified translation**. Each footnote must receive a complete English translation and be checked against the original Hebrew; then independently verify or approve its exact Hebrew-word attachment before publishing. The importer should fail closed on any missing translation or mismatch.

The separate standalone prepared package provided in chat includes the 2,492 original note texts and the import validation script.
